# ⚔️ Anime Conquer

A browser-based multiplayer card conquest game featuring characters from 8 anime universes.

## 🎮 Play Now


## 📺 Supported Verses
- Naruto Shippuden
- One Piece
- Bleach
- Jujutsu Kaisen
- Demon Slayer
- My Hero Academia
- Hunter x Hunter
- Fire Force

## 🕹️ Game Modes
- **Conquest** — Eliminate all opponents by destroying their units
- **Showdown** — Race to claim tiles, then battle all-vs-all
- **Ability Mode** — Every character has a unique power

## 👥 Multiplayer
Supports 2-4 players locally, or online via room codes.

## 🛠️ Built With
- HTML / CSS / JavaScript (no frameworks)
- PeerJS for online multiplayer
